# Portfolio

Personal portfolio site for Naveen Kumaar — GenAI / Data Scientist building
config-driven multi-agent platforms and cascaded voice agents. Built with
React + Vite.

Live project writeups referenced on the site come from the
[design journal](https://github.com/Naveenkumaar/design-journal).

## Develop

```bash
npm install
npm run dev
```

## Deploy

Builds to `dist/` and deploys to the `gh-pages` branch:

```bash
npm run deploy
```

Then enable GitHub Pages on the `gh-pages` branch in repo settings.
